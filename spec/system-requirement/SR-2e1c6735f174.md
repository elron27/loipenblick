Das System muss so hochladen, dass Besucher nie einen halben Stand sehen: zuerst neue Daten-Dateien mit Inhalts-Hash im Namen, zuletzt index.json, HTML und Service Worker per Umbenennen. Dateien, auf die weder der aktuelle noch der vorige Stand verweist, werden danach gelöscht.
