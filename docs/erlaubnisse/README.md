# Erlaubnisse der Quellbetreiber

Hier liegt für jede Quelle mit `erlaubnis: liegt_vor` in `config/sources.yaml` der Beleg: wer, wann, was genau
erlaubt wurde und unter welcher Bedingung (B31). Die Konfigurationsprüfung lehnt `liegt_vor` ohne Beleg ab.

Nur Name, Funktion und Firma der Absender, keine Telefonnummern, keine privaten Adressen. Die Original-Mail
bleibt in Stefans Postfach.

|---|---|---|
